# 将来検討：規格ファイル機能（本アプリのスコープ外・設計メモ）

このドキュメントは実装対象ではない。ユーザーとの会話で共有された将来構想を記録するためのメモ。

## 背景

現状の「テストレポート作成資料アプリ」では、`ReportStandard`（レポート作成規格）は規格名程度の情報しか持たない。一方、将来的に別途構築予定の以下のツール群では、規格ごとの試験内容そのものを参照する必要がある。

- データシートテンプレート（試験結果を作成するためのツール）
- テストプラン作成テンプレート（試験計画を作成するためのツール）

これらは現時点では未着手・未設計（既存のExcel/Wordファイルとしても存在しない）。

## 構想（会話で確認した内容）

「規格ファイル」を本アプリのプロジェクトデータとは別に、規格単位で保存・呼び出しできるファイルとして管理する。1件の規格ファイルが持つべき情報として、以下が挙げられた。

- 規格名・規格番号（例：CISPR 32）
- 試験項目リスト（放射エミッション、伝導エミッション等）
- 各試験項目の判定基準・限度値
- 試験レベル・severity（イミュニティ試験のレベル等）
- 各試験項目の特記事項・備考

## 現時点での結論

今回のセッションでは実装しない。本アプリの`ReportStandard`データモデル・UIには影響を与えない。将来、データシートテンプレート／テストプラン作成テンプレートの具体的な要件（既存フォーマットの有無、ファイル形式等）が固まった時点で、別途設計・実装を検討する。
